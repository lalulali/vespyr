# Step-0 Sharpening Contract (shared — brainstorming + elicitation)

Single source of truth for topic sharpening. Skills cite this file with their skill-specific output use; they do not restate the four steps. Vague input produces vague output — sharpen before any method, matching, or critique.

## The four steps

1. **Restate the target** — one sentence: what is under discussion, and what kind of output is needed (skill fills in its output kinds).
2. **Surface the fuzz** — what is ambiguous, unstated, or assumed: max 5 concrete bullets (missing constraints, undefined success term, hidden audience, unstated scope). No generic filler.
3. **Emit the sharpened topic** — one precise sentence with explicit in/out-of-scope boundaries. If the topic is already precise, say so and move on — do not manufacture ambiguity for ceremony.
4. **Confirm with the user** — present the sharpened topic and HALT ("Correct, or edit?"). Only the confirmed statement drives the next step (skill fills in: method-selection context, telemetry `--topic`).
