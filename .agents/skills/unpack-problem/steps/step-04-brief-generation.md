# Step 4 — Brief Generation

> **Tracker:** `node .agents/scripts/step_tracker.js begin --skill unpack-problem --step 4` at step start; `complete --skill unpack-problem --step 4` at step close.

`@product-manager` compiles the full problem-space brief and hands off to the next phase.

## Workflow

### 4a. Compile problem-space brief

Write `artifacts/output/02-research/problem-space-brief.md` using the template at `.agents/templates/discovery/problem-brief.md`:

```markdown
# Problem Space Brief — {problem summary}
**Date:** YYYY-MM-DD
**Generated by:** @product-manager, @user-researcher
**Mode:** {guided / automated / combination}

## Problem Statement
{User segment} experiences {symptom} when {context}, which causes {impact}.

## Root Cause
{root cause finding from analysis}

## Affected Users
- **Segment:** {who}
- **Current behavior:** {what they do now}
- **Emotional state:** {how they feel}

## Current Journey (Pain Point)
{journey stage where the problem manifests}

## Jobs-to-be-Done
| JTBD | HMW Opportunity |
|------|----------------|
| When {context}, I want to {action}, so I can {outcome}. | How might we {opportunity}? |

## Selected Solution Concept
- **Intervention:** {what changes}
- **Hypothesis:** {testable statement}
- **Confidence:** {High/Med/Low}
- **Verdict:** `[VERDICT: GO|RESHAPE|NO-GO]` — {one-line rationale from step 3d}

## Supporting Artifacts
- [Root cause analysis](root-cause-analysis.md)
- [Empathy map](empathy-map.md)
- [Journey map](journey-map.md)
- [JTBD + HMW](jtbd-hmw.md)

## Next Step
- [ ] `/validate-idea` — stress-test the selected concept
- [ ] `/shape-up` — structure into a design-ready brief
- [ ] `/explore-idea` — research market and competitors

## Decision Gate
[GATE: GO|RESHAPE|NO-GO — <reason>] — the selected concept's step-3 `[VERDICT:]` rolled up as the brief's final routing decision. Present the `[HANDOFF: ...]` marker alongside it in the handoff.
```

### 4b. Memory closeout

```
@memory-controller session-write
Worked on: Problem exploration — {problem summary}
Mode: {guided / automated / combination}
Key findings:
- Root cause: {finding}
- Solution concept selected: {concept}
Next step: {recommended workflow}
```

### 4c. State machine

Run:
```bash
node .agents/scripts/orchestrator_state.js complete --agent product-manager --artifact 02-research/problem-space-brief.md
```

## Handoff

The brief ends with a Decision Gate on the selected solution concept, recorded as a parseable marker before the handoff marker: `[GATE: GO|RESHAPE|NO-GO — <reason>]`. `[GO]` = ready to stress-test; `[RESHAPE]` = problem framing needs another pass (re-run steps 1-3); `[NO-GO]` = problem not worth solving — document why and stop. A brief without a gate is a document, not a decision.

Present the brief to the user with a clear recommendation, recorded as a parseable marker — `[HANDOFF: validate-idea|shape-up|explore-idea]`:
- "This concept is ready to test → I recommend loading `/validate-idea`"
- "This needs more structure before design → I recommend loading `/shape-up`"
- "We need market validation → I recommend loading `/explore-idea`"

## Delegation
- **Memory:** @memory-controller for session-write
