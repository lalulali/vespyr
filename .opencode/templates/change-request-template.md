# Change Requests

> **Used by:** Any agent discovering issues with upstream artifacts
> **Save to:** `artifacts/output/04-planning/change-requests.md`

Rules:
- File a CR instead of re-invoking an upstream agent
- Upstream agent responds to **only this request**, not its full workflow
- No agent may re-process an entire artifact in response to a CR
- If unresolved after one response, escalate to decision authority (see GUARDRAILS.md)
